# Balance reports

Generated by `pnpm balance` (`packages/store/src/balance/`) from the real flight engine.

- `baseline-v1.md`: the economy as of S02 (2026-10-05), before any balance change. Keep it as the "before" table.
- `latest.md`: regenerate with `pnpm balance` and commit it with every economy change, so the diff shows the before/after.
- For a new baseline after a deliberate rebalance: `BALANCE_OUT=docs/overhaul/balance/baseline-v2.md pnpm balance`.

The files are excluded from Prettier (`.prettierignore`) so they stay byte-identical to the generator output. Re-running on unchanged code produces no diff.
